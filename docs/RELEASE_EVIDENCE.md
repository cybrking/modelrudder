# Community preview evidence — October 7, 2026

The source snapshot contains the current allowlisted local client, relevant client regression tests, its packaging/installer and empty direct-classifier configuration. It does not include private Git history, backend/billing infrastructure, customer records, internal business documents, raw evaluation traces or workspace projects.

Codex 0.159.3 has historical protocol evidence. Codex 0.160.1 has recorded initialization, fresh-thread creation, model-setting and read-only permission checks. This is not full interactive TUI certification. The launcher rejects other versions.

Offline client tests use synthetic classifier/native-provider fixtures and exercise transport forwarding, permission preservation, fallback, timeout/cancellation, context eligibility, effort policy, metadata logs, and release install/rollback/uninstall. CI runs those tests and TypeScript checking with Node 24 and 26 on macOS and builds release artifacts. Inspect the actual passing run for this tag before relying on it.

No calibrated routing confidence, independently verified production task quality, subscription-bill savings or general native TUI compatibility is claimed. Clef, Claude and commercial API execution are not included. Observe mode is recommended initially.

The original private development tree passed 315 offline tests and TypeScript checks immediately before export. Those include backend/evaluation tests excluded from this client-only repository; they are not this public repository's test count. Exact exported-tree validation is recorded in the release notes.
